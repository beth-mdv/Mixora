
# Mixora — Deployment Guide

## Project Overview

Mixora is a static responsive coffee landing page built with HTML5, CSS3, Tailwind CSS v4, and JavaScript.

## Production Files

The deployed website requires:

- `index.html`
- `css/style.css`
- `css/tailwind.css`
- `assets/icons/`
- `assets/images/`

The Tailwind CSS file is already compiled for production.

## GitHub Pages

1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Select Deploy from a branch.
4. Choose the `main` branch and `/ (root)` folder.
5. Save and open the published URL.

## Netlify

The landing page is also available at:

https://symphonious-starburst-ad957a.netlify.app/

For a Git-connected deployment, use the `main` branch with the project root as the publish directory. No build command is required when using the precompiled CSS.

## Verification Checklist

- [ ] The website opens successfully.
- [ ] CSS and WebP images load correctly.
- [ ] Mobile navigation works.
- [ ] YouTube and Google Maps embeds are displayed.
- [ ] No unexpected horizontal scrolling occurs.
- [ ] The browser Console has no site-related errors.
