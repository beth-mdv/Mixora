
# Mixora ☕

Mixora is a responsive coffee e-commerce landing page where users can explore signature coffee blends and discover the concept of creating personalized coffee.

## Features

- Responsive desktop and mobile layouts
- Interactive mobile navigation (Side Drawer)
- Coffee blend search
- Interactive product cards
- YouTube brewing tutorial
- Embedded Google Maps demo location
- Optimized WebP images

## Technologies

- HTML5
- CSS3
- Tailwind CSS v4
- JavaScript
- Git & GitHub
- Netlify

## Live Website

https://symphonious-starburst-ad957a.netlify.app/

## Running Locally

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.

## Landing Page Sections

1. Header — navigation, search, cart and profile.
2. Hero — main brand message and featured coffee.
3. About Mixora — brand concept and benefits.
4. How It Works — four steps of creating a blend.
5. How to Brew — embedded YouTube tutorial.
6. Your Mix — personalized coffee experience.
7. Our Blends — four signature coffee products.
8. Find Us — embedded Google Maps demo location.
9. Footer — navigation and brand information.

## Responsive Design

The landing page supports desktop, tablet and mobile layouts.

Responsive behavior includes:
- Mobile navigation drawer.
- Adaptive typography and product grids.
- Responsive YouTube and Google Maps embeds.
- Decorative SVG section borders.
- Optimized WebP images.
